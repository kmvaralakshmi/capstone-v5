# Autonomous AI Multi-Agent ESG System - Phase 3

This package keeps the original Phase 3 deterministic ESG computation modules and adds an **LLM-driven autonomous agent layer**.

## What changed

The previous seven agents were deterministic Python components. In this version, each specialist has:
- a goal;
- a set of callable tools;
- observations returned by those tools;
- an LLM-driven decision loop that chooses the next tool with `tool_choice="auto"`;
- a trace recording the tool selected, arguments, and returned observation.

The existing deterministic modules remain the trusted computation layer. The LLM is the planner/decision-maker that selects among those tools and can retry or change strategy based on observations.

### Agent 1 example

Goal: extract 18 BRSR metrics.

Available tools include `inspect_pdf`, `search_document`, `extract_table`, `extract_metric_with_strategy`, and `validate_metric`.

The model may decide to inspect a PDF, search for a metric, inspect candidate tables, choose `table` vs `keyword_context` vs `text_window`, validate the result, and only then continue or try another strategy. The next action is not hard-coded as a fixed `if/else` sequence.

## Important: API key

Autonomous mode requires an OpenAI API key. Do **not** commit the key to GitHub or put it inside this ZIP.

1. Create a virtual environment.
2. Install requirements.
3. Copy `.env.example` to `.env`.
4. Put your key in `OPENAI_API_KEY`.
5. Run the autonomous pipeline.

Windows:

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
copy .env.example .env
```

Then edit `.env` and set `OPENAI_API_KEY`.

Run:

```bat
python run_autonomous_pipeline.py
```

You can run one agent while testing:

```bat
python run_autonomous_pipeline.py --agents agent1
```

## Architecture

```text
                    LLM Supervisor / Run Context
                              |
      +-----------------------+-----------------------+
      |                       |                       |
 Agent 1                 Agent 2 ...              Agent 7
 BRSR                    Environment               Explainability
      |                       |                       |
  dynamic tool           dynamic tool           dynamic tool
  selection              selection              selection
      |                       |                       |
 deterministic PDF      deterministic AQI      deterministic scoring
 / validation tools     computation tools      / explanation tools
```

The seven agents are still specialized and communicate through generated files in `processed-data/`. The new autonomous layer decides tool usage within each specialization.

## Evidence of autonomy

Every run writes JSON traces to:

`processed-data/ai_agent_traces/`

A trace contains the agent's selected tool, arguments, tool observation, timing, and final response. These traces are useful during a viva to demonstrate that tool selection was model-driven rather than a fixed program sequence.

## Academic wording

Use this accurate description:

> "The system uses an LLM-driven autonomous multi-agent architecture. Each specialized ESG agent is assigned a goal and a set of deterministic domain tools. The language model observes tool outputs and dynamically selects the next action through function calling. The deterministic tools perform the auditable calculations and data extraction, while the AI agent provides goal-directed planning and tool selection."

Do not claim that every numerical calculation is generated by AI; those calculations remain deterministic for reproducibility and auditability.

## Current original Phase 3 modules

The original agents remain in `agents/agent1_brsr_extractor.py` through `agents/agent7_explainable_ai.py`. They are intentionally preserved because they contain the tested ESG domain logic. `ai_agents/` is the autonomous reasoning/orchestration layer on top of those tools.
