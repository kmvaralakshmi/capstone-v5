# Phase 3 target-company configuration

`target_companies_50.csv` is the Phase 3 50-company candidate universe.

Important:
- The existing Phase 2/early Phase 3 implementation has verified BRSR manifests for 20 companies.
- The 50-company CSV is a scalable target list, not a claim that all 50 BRSR PDFs are already present.
- Only a company with a validated BRSR PDF and compatible downstream data should be included in a final published 50-company result.
- The downloader audit log is the source of truth for download/validation status.
